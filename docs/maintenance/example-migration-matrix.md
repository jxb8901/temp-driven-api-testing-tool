# Example and Default Package migration matrix

Nonconvertible Templates and workbooks live in the registerable `packages/legacy` package. Template IDs and workbook Case IDs are unchanged. `packages/legacy/flows/common/` and `packages/legacy/tools/` are package-local dependency copies; the canonical current copies stay in `packages/default`. `runtimeSupport` says whether ATT can execute the resource today. `ciRunnable` marks only the offline Native Suite fixture set; `no` does not mean the file is non-executable.

The machine-readable copy is [example-inventory.json](../example-inventory.json).
