# CLI interfaces

ATT 4.2.6 ships the legacy Local CLI and the ATT Remote compatibility client.

| Interface | Status | Guide |
|---|---|---|
| Local commands: run, validate, snapshot, debug, load, docs, report, build, clean | Current in 4.2.6 | [CLI Reference](../../reference/cli.md) |
| att remote profiles, Jobs, events and artifacts | Legacy-compatible in 4.2.6 | [ATT Remote guide](../../remote-client.md) |
| Common run, load and validate grammar with Local/Server routing | Planned; not released | [Proposed CLI vNext](vnext-proposed.md) |

The vNext proposal does not remove existing Server, Studio or REST capabilities. Job management, detach and other #294 P3 proposals are outside that grammar.
