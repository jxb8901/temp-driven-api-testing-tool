# ATT 內部限制參考與容量矩陣

本文件列出 Engine、Worker、Server、artifact 發布及 Studio 的容量邊界。權威機器可讀清單：[internal-limits-inventory.json](internal-limits-inventory.json)。目前的安全限制有意保持不變；遇到容量問題時，先採用有界回應、分頁、精簡 evidence 及核准 artifact。

**Inventory schema:** `att-internal-limits/v1`; entries: 97.

## 結果分類與閱讀方式

`EXECUTION_ERROR` 表示工作執行失敗；`SUBMISSION_REJECTED` 表示請求未獲接納；`ARCHIVE_FAILED` 與 `ARTIFACT_OMITTED` 描述 artifact 發布結果；`DATA_TRUNCATED`、`HISTORY_EVICTED`、`METRICS_SAMPLED` 表示資料呈現或保留有限。這些分類不會改寫執行 `status`、`exitCode`、threshold verdict 或 archive lifecycle。沒有量測資料會顯示為 unavailable，不代表零。

| 症狀／診斷 | 子系統 | 安全處理 |
|---|---|---|
| `HTTP 413`／request 或 inspection response 過大 | Server admission／inspection | 縮小 request，採用分頁、篩選及 bounded source excerpt。 |
| `ATT-RESOURCE-LIMIT`／HTTP 413 | Engine package inspection | 縮小掃描範圍或拆分 Package；這是確定性限制，不要原樣重試。超大工作簿則以 HTTP 200 回傳部分索引，該 suite 標為 invalid 並附 `ATT-RESOURCE-CASE-INVALID`。 |
| `HTTP 429`、`503` 或 `504` | Server queue／inspection／SSE | 降低提交尖峰；只有 transient queue saturation 才在容量釋放後重試，並分開檢查 inspection deadline 及 SSE observer。 |
| `ATT-ARCHIVE-NOT-READY`／409 | Artifact publication | PENDING 或 ARCHIVING 時刷新 archive 狀態，等到 READY 後再開啟；只有 FAILED 才是 archive failure。 |
| `DB_POOL_TIMEOUT`、`MQ_POOL_TIMEOUT`、`HTTP_POOL_TIMEOUT` | Engine helper pool | 分別檢查 active／idle／waiting／timeout；先降低爭用及持有時間。 |
| `*_RESPONSE_TOO_LARGE` | Engine DB／MQ／HTTP | 先投影欄位、分頁或縮減 evidence，再考慮設定範圍內的調整。 |
| `ATT-WORKER-EVENT-TRUNCATED`、`ATT-JOURNAL-EVENT-TRUNCATED` | Worker／Journal transport | 以 compact result 作主資訊；從 archive 或分頁取得核准細節。不要把單獨截斷當作 ERROR。 |
| `ATT-LOAD-EVIDENCE-QUOTA` | LOAD evidence | 查看 skipped evidence count； aggregate metrics 保持完整，先調整 evidence selection／sampling。 |
| `LOAD_REPORT_WRITE_FAILED` | LOAD report publication | 執行狀態及 exit code 保持原值；縮減 detail budget 使用量或待儲存空間可用後重試。 |
| `ATT-ARCHIVE-LIMIT-EXCEEDED` 或 `ATT-ARTIFACT-OMITTED` | Artifact publication | 分別查看 archive FAILED 或 omission manifest；執行狀態不會因此變更。 |
| `METRICS_SAMPLED`／bucket coverage 不完整 | LOAD metrics | 按 observation count、sample count 及 coverage window 解讀圖表。完整長時間圖表需另行設計。 |
| `ATT-VALIDATION-LIMIT` | Validation budget | 使用 selected scope、縮小 dependency closure，並保留 partial coverage 診斷。 |
